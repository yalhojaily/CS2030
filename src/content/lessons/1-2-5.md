## Graphs are everywhere in software

A social network, the internet's routers, a road map, the call graph of a program, the dependencies between packages, the states of a protocol, the links between web pages: all of these are **graphs**, things connected to things. Learn the vocabulary and a few theorems once, and you can reason about all of them. Lesson 1.4.6 will add the algorithms (BFS, DFS, Dijkstra) that run on them.

## Definitions

<div class="box def">

<span class="tag">Definition</span>

A **(simple) graph** $G = (V, E)$ is a set of **vertices** $V$ and a set $E$ of **edges**, where each edge is an unordered pair $\{u, v\}$ of distinct vertices. Then $u$ and $v$ are **adjacent**, or **neighbours**, and the edge is **incident** to both.

</div>

Variations you will meet:

- A **multigraph** allows several edges between the same pair; a **loop** joins a vertex to itself.
- A **directed graph** (digraph) has edges that are **ordered** pairs $(u, v)$, drawn as arrows. "A follows B" and "package A depends on package B" are directed.
- A **weighted graph** has a number on each edge: distance, latency, cost.

The **degree** $\deg(v)$ of a vertex is the number of edges incident to it (a loop counts twice). In a digraph, a vertex has an **in-degree** and an **out-degree**.

### The handshake lemma

<div class="box thm">

<span class="tag">Theorem (handshake lemma)</span>

In any graph, $\displaystyle \sum_{v \in V} \deg(v) = 2|E|$.

</div>

*Proof.* Each edge $\{u, v\}$ contributes exactly 1 to $\deg(u)$ and 1 to $\deg(v)$, so exactly 2 to the sum. Summing over all edges gives $2|E|$. $\blacksquare$

<div class="box thm">

<span class="tag">Corollary</span>

Every graph has an **even** number of vertices of odd degree.

</div>

*Proof.* Split the sum of degrees into the sum over even-degree vertices and the sum over odd-degree vertices. The total is even (it is $2|E|$) and the even part is even, so the odd part is even. A sum of odd numbers is even only if there is an even number of them. $\blacksquare$

So there can be no party of 7 people where everyone shakes hands with exactly 3 others: that would be 7 vertices of odd degree.

## Special graphs

| Graph | Description | Vertices | Edges |
|:-|:-|:-:|:-:|
| Complete graph $K_n$ | every pair adjacent | $n$ | $\binom{n}{2} = \frac{n(n-1)}{2}$ |
| Cycle $C_n$ ($n \ge 3$) | a ring | $n$ | $n$ |
| Path $P_n$ | a line | $n$ | $n - 1$ |
| Complete bipartite $K_{m,n}$ | two sides, every cross pair adjacent | $m + n$ | $mn$ |
| Hypercube $Q_n$ | bit strings of length $n$, adjacent if they differ in one bit | $2^n$ | $n 2^{n-1}$ |

A graph is **bipartite** if its vertices can be split into two sets so that every edge goes between the sets. Users and the products they bought form a bipartite graph; so do jobs and the machines that can run them.

<div class="box thm">

<span class="tag">Theorem</span>

A graph is bipartite if and only if it has no cycle of odd length.

</div>

One direction is easy: walking around a cycle in a bipartite graph alternates sides, so you return to the start only after an even number of steps. The other direction is proved by 2-colouring with BFS from any vertex (colour by distance parity), which is also the algorithm for testing bipartiteness; the analyser below does exactly this.

## Representing graphs in a program

| | Adjacency matrix | Adjacency list |
|:-|:-|:-|
| Structure | $n \times n$ array, $A_{uv} = 1$ if $\{u,v\} \in E$ | for each vertex, a list of its neighbours |
| Space | $\Theta(n^2)$ | $\Theta(n + m)$ |
| "Is $u$ adjacent to $v$?" | $O(1)$ | $O(\deg u)$ |
| "List neighbours of $u$" | $O(n)$ | $O(\deg u)$ |
| Best for | dense graphs, matrix algebra | sparse graphs (most real ones) |

Here $n = |V|$, $m = |E|$. A social network with a billion users and a few hundred friends each is extremely sparse, so it is stored as lists. A neat fact about the matrix: the entry $(A^k)_{uv}$ counts the walks of length $k$ from $u$ to $v$, which you can prove by induction on $k$.

## Paths and connectivity

<div class="box def">

<span class="tag">Definitions</span>

A **walk** is a sequence of vertices where consecutive ones are adjacent. A **path** is a walk with no repeated vertex. A **cycle** is a walk of length at least 3 that starts and ends at the same vertex and repeats no other vertex. A graph is **connected** if there is a path between every pair of vertices. The **connected components** are the maximal connected pieces.

</div>

"Is in the same component as" is an equivalence relation (lesson 1.2.2): reflexive, symmetric, and transitive because two paths can be joined. Its classes are exactly the connected components.

<div class="box thm">

<span class="tag">Theorem</span>

A connected graph with $n$ vertices has at least $n - 1$ edges.

</div>

*Proof sketch.* Start with $n$ isolated vertices: $n$ components. Adding one edge reduces the number of components by at most 1. To reach 1 component you need at least $n - 1$ edges. (Make this an induction on the number of edges in exercise 6.) $\blacksquare$

This is the minimum cost of any network that keeps every node reachable.

## Euler and Hamilton: two similar questions, two different worlds

In 1736, the city of Königsberg had seven bridges joining four land masses. Could you walk across every bridge exactly once? Euler modelled the land as vertices and the bridges as edges, and founded graph theory by answering "no".

<div class="box def">

<span class="tag">Definitions</span>

An **Euler path** uses every **edge** exactly once; an **Euler circuit** is an Euler path that returns to its start. A **Hamilton path** visits every **vertex** exactly once; a **Hamilton cycle** returns to its start.

</div>

<div class="box thm">

<span class="tag">Theorem (Euler)</span>

A connected graph (ignoring isolated vertices) has an Euler circuit if and only if every vertex has even degree. It has an Euler path that is not a circuit if and only if exactly two vertices have odd degree; the path must start at one and end at the other.

</div>

*Why even degree is necessary:* each time a circuit passes through a vertex, it uses one edge to enter and one to leave, so edges at each vertex pair up. Königsberg has four vertices of odd degree (5, 3, 3, 3), so no such walk exists. (Sufficiency is proved by building the circuit; see Rosen 10.5.)

<div data-widget="graph" data-g="A B\nA B\nA C\nA C\nA D\nB D\nC D"></div>

Now the twist. Euler's question is answered by checking degrees, which takes linear time. The Hamilton question, which looks almost the same, is **NP-complete**: nobody knows an efficient algorithm, and finding one would settle the most famous open problem in computer science. The travelling-salesman problem, finding the cheapest Hamilton cycle, inherits this hardness. Recognising which of two similar-looking problems you have is a core engineering skill.

## Trees

<div class="box def">

<span class="tag">Definition</span>

A **tree** is a connected graph with no cycles. A **forest** is a graph with no cycles (each component is a tree). A vertex of degree 1 in a tree is a **leaf**.

</div>

<div class="box thm">

<span class="tag">Theorem</span>

For a graph $T$ with $n$ vertices, the following are equivalent:
1. $T$ is a tree (connected and acyclic);
2. there is exactly one path between every pair of vertices;
3. $T$ is connected and has $n - 1$ edges;
4. $T$ is acyclic and has $n - 1$ edges;
5. $T$ is connected, but removing any edge disconnects it.

</div>

The key step is a lemma: **every tree with $n \ge 2$ vertices has at least two leaves.** *Proof:* take a longest path in the tree. Its endpoints must be leaves: an endpoint with another neighbour would either extend the path (contradicting "longest") or close a cycle (contradicting "acyclic"). $\blacksquare$

<div class="box thm">

<span class="tag">Theorem</span>

Every tree with $n \ge 1$ vertices has exactly $n - 1$ edges.

</div>

*Proof by induction on $n$.* **Base** ($n = 1$): one vertex, no edges. **Step.** Assume every tree with $k$ vertices has $k - 1$ edges, and let $T$ have $k + 1 \ge 2$ vertices. By the lemma, $T$ has a leaf $v$. Removing $v$ and its one edge leaves a graph that is still connected (no path between two other vertices passed through a leaf) and still acyclic, so it is a tree with $k$ vertices and, by the IH, $k - 1$ edges. Putting $v$ back adds one edge: $k$ edges. $\blacksquare$

Trees are the minimally connected graphs: one fewer edge disconnects them, one more creates a cycle. File systems, the DOM, abstract syntax trees, organisation charts and spanning trees in networks (used to prevent broadcast loops in Ethernet) are all trees.

A **rooted tree** picks one vertex as the root, giving every other vertex a parent. The binary trees of lesson 1.2.3 and the search trees of lesson 1.3.5 are rooted trees.

## Directed acyclic graphs

A **DAG** is a directed graph with no directed cycle. Build steps, course prerequisites, spreadsheet cell dependencies and Git's commit history are DAGs.

<div class="box thm">

<span class="tag">Theorem</span>

A directed graph has a **topological order** (a listing of all vertices in which every edge points forward) if and only if it is acyclic.

</div>

If there were a cycle, its vertices would each have to come before the next one, all the way round, which is impossible. Conversely, every finite DAG has a vertex with in-degree 0 (otherwise you could walk backwards forever and, with finitely many vertices, would repeat one, forming a cycle). List that vertex first, delete it, and repeat on the remaining DAG: an induction on the number of vertices. This is Kahn's algorithm, which lesson 1.4.6 implements.

## Colouring and planarity, briefly

A **proper colouring** gives adjacent vertices different colours; the fewest colours needed is the **chromatic number** $\chi(G)$. Scheduling exams so that no student has two at once is a colouring problem (exams are vertices, an edge joins exams that share a student, colours are time slots). So is register allocation in compilers. Deciding whether $\chi(G) \le 3$ is NP-complete; bipartite graphs are exactly those with $\chi(G) \le 2$.

A graph is **planar** if it can be drawn without crossing edges. For a connected planar drawing with $v$ vertices, $e$ edges and $f$ faces (counting the outer one), **Euler's formula** says $v - e + f = 2$. From it one derives $e \le 3v - 6$ for simple planar graphs with $v \ge 3$; since $K_5$ has $10 > 3 \cdot 5 - 6 = 9$ edges, $K_5$ is not planar. And every planar graph can be coloured with 4 colours, a theorem first proved in 1976 with substantial computer assistance.

## Exercises

<div class="exercise">

<span class="tag">Exercise 1</span><span class="lvl-tag">★ basic</span>

A graph has 10 vertices of degree 3 and the rest of degree 4, and 25 edges in total. How many vertices does it have?

<details><summary>Solution</summary>

Let $x$ be the number of degree-4 vertices. Handshake: $10 \cdot 3 + 4x = 2 \cdot 25 = 50$, so $x = 5$. Total: 15 vertices.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 2</span><span class="lvl-tag">★ basic</span>

Is there a simple graph with degree sequence (a) 3, 3, 3, 1; (b) 3, 3, 2, 2, 1; (c) 4, 4, 4, 2, 2 on five vertices?

<details><summary>Solution</summary>

(a) **No.** The sum is 10, fine, but with 4 vertices a vertex of degree 3 is adjacent to all others. Three such vertices would each be adjacent to the fourth, giving it degree at least 3, not 1.
(b) **No.** The sum is 11, which is odd; the handshake lemma forbids it.
(c) **No.** The sum is 16, which is even, so the handshake lemma does not rule it out. But on 5 vertices, a vertex of degree 4 is adjacent to all four others. Three such vertices means each of the remaining two vertices is adjacent to all three of them, giving it degree at least 3, not 2.

The lesson of (a) and (c): an even degree sum is necessary, not sufficient. Always check what the highest-degree vertices force on the others.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 3</span><span class="lvl-tag">★★ core</span>

For which $n$ does $K_n$ have an Euler circuit? For which $m, n$ does $K_{m,n}$?

<details><summary>Solution</summary>

In $K_n$ every vertex has degree $n - 1$, so an Euler circuit exists exactly when $n - 1$ is even, i.e. $n$ is odd (and $n \ge 3$; $K_1$ trivially).
In $K_{m,n}$, vertices on one side have degree $n$ and on the other side degree $m$. An Euler circuit exists exactly when both $m$ and $n$ are even.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 4</span><span class="lvl-tag">★★ core</span>

Show that $C_n$ is bipartite if and only if $n$ is even. Check $C_5$ and $C_6$ in the analyser.

<details><summary>Solution</summary>

If $n$ is even, colour the vertices around the cycle alternately; consecutive vertices differ, and the last vertex (even position) differs from the first. If $n$ is odd, $C_n$ is itself an odd cycle, so by the theorem it is not bipartite. Directly: alternating colours around an odd cycle forces the last vertex to have the same colour as the first, and they are adjacent.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 5</span><span class="lvl-tag">★★ core</span>

A tree has 2 vertices of degree 3, 3 vertices of degree 2, and all other vertices are leaves. How many leaves does it have?

<details><summary>Solution</summary>

Let $\ell$ be the number of leaves. Vertices: $n = 5 + \ell$; edges: $n - 1 = 4 + \ell$. Handshake: $2 \cdot 3 + 3 \cdot 2 + \ell = 2(4 + \ell)$, so $12 + \ell = 8 + 2\ell$, giving $\ell = 4$.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 6</span><span class="lvl-tag">★★ core</span>

Prove by induction on the number of edges that a graph with $n$ vertices and $m$ edges has at least $n - m$ connected components. Deduce that a connected graph has at least $n - 1$ edges.

<details><summary>Solution</summary>

**Base** ($m = 0$): $n$ isolated vertices, so exactly $n \ge n - 0$ components. **Step.** Assume the claim for graphs with $k$ edges. Take a graph $G$ with $k + 1$ edges and remove one edge $e$, giving $G'$ with $k$ edges and, by the IH, at least $n - k$ components. Adding $e$ back either joins two components into one or lands inside one component, so $G$ has at least $n - k - 1 = n - (k+1)$ components. $\blacksquare$
A connected graph has 1 component, so $1 \ge n - m$, i.e. $m \ge n - 1$.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 7</span><span class="lvl-tag">★★ core</span>

Show that in any group of 6 or more people at a meetup, there are two people who know the same number of others in the group (acquaintance is mutual).

<details><summary>Solution</summary>

Model people as vertices of a simple graph with $n \ge 2$ vertices. Possible degrees are $0, 1, \dots, n-1$: $n$ values. But 0 and $n - 1$ cannot both occur (a vertex adjacent to everyone rules out an isolated vertex). So at most $n - 1$ distinct degrees are available for $n$ vertices, and by pigeonhole two vertices share a degree. (This works for any $n \ge 2$, not only 6.) $\blacksquare$

</details>
</div>

<span class="tag">Exercise 8</span><span class="lvl-tag">★★ core</span>

Courses: Algorithms requires Data Structures and Discrete Math; Data Structures requires Programming; Operating Systems requires Data Structures and Architecture; Architecture requires Programming. Draw the DAG and give two different valid topological orders.

<details><summary>Solution</summary>

Edges (prerequisite → course): Prog → DS, Prog → Arch, DS → Alg, Discrete → Alg, DS → OS, Arch → OS.
Valid orders include: Prog, Discrete, DS, Arch, Alg, OS; and Discrete, Prog, Arch, DS, OS, Alg. Any order where each edge points forward is valid; there are several because the order is only partial.

</details>

<div class="exercise">

<span class="tag">Exercise 9</span><span class="lvl-tag">★★★ stretch</span>

Prove that if a connected graph has exactly two vertices of odd degree, then adding one edge between them gives a graph with an Euler circuit; use this to explain the Euler-path part of Euler's theorem. Then decide whether the house-shaped graph (a square $a, b, c, d$ with a roof vertex $e$ joined to $a$ and $b$, plus both diagonals of the square) can be drawn without lifting the pen.

<details><summary>Solution</summary>

Adding an edge between the two odd vertices $u, v$ raises both degrees by one, making every degree even; the graph stays connected, so by Euler's theorem it has an Euler circuit. Removing the added edge from that circuit leaves a walk using every original edge exactly once, starting at $u$ and ending at $v$: an Euler path. (If $u$ and $v$ were already adjacent, the result is a multigraph, which the theorem also covers.)

House: degrees are $a$: $b, d, e, c$ (diagonal) = 4; $b$: $a, c, e, d$ = 4; $c$: $b, d, a$ = 3; $d$: $a, c, b$ = 3; $e$: 2. Exactly two odd vertices ($c$ and $d$), and it is connected, so **yes**: start at $c$ and end at $d$ (or vice versa). Check it in the analyser.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 10</span><span class="lvl-tag">★★★ stretch</span>

Let $A$ be the adjacency matrix of a simple graph. Prove by induction on $k \ge 1$ that $(A^k)_{uv}$ equals the number of walks of length $k$ from $u$ to $v$. What does the diagonal of $A^2$ tell you? What does $\frac{1}{6}\operatorname{trace}(A^3)$ count?

<details><summary>Solution</summary>

**Base** ($k = 1$): $A_{uv} = 1$ exactly when there is a walk of length 1 (an edge) from $u$ to $v$. **Step.** Assume $(A^k)_{uw}$ counts walks of length $k$ from $u$ to $w$. A walk of length $k + 1$ from $u$ to $v$ is a walk of length $k$ from $u$ to some $w$, followed by an edge $w \to v$. Summing over $w$: $\sum_w (A^k)_{uw} A_{wv} = (A^{k+1})_{uv}$. $\blacksquare$

$(A^2)_{uu}$ counts walks $u \to w \to u$, one per neighbour, so it is $\deg(u)$. $\operatorname{trace}(A^3)$ counts closed walks of length 3, which are triangles; each triangle is counted 6 times (3 starting vertices × 2 directions), so $\frac16 \operatorname{trace}(A^3)$ is the number of triangles. Social networks use this kind of count to measure clustering.

</details>
</div>

## Summary

- A graph is vertices and edges; degree sums to twice the number of edges, so odd-degree vertices come in pairs.
- Adjacency lists suit sparse graphs; adjacency matrices suit dense ones and algebra.
- Components are the classes of the "reachable" equivalence relation; a connected graph needs at least $n - 1$ edges.
- Euler circuits exist exactly when every degree is even; Hamilton cycles are NP-complete. Similar questions can have very different difficulty.
- Trees are connected, acyclic, and have exactly $n - 1$ edges. DAGs are exactly the directed graphs with a topological order.
- Bipartite means 2-colourable means no odd cycle.
