## Sets: the vocabulary of data

<div class="box def">

<span class="tag">Definition</span>

A **set** is an unordered collection of distinct objects, called its **elements**. We write $x \in A$ when $x$ is an element of $A$, and $x \notin A$ when it is not.

</div>

Two facts follow directly. Order does not matter, so $\{1, 2, 3\} = \{3, 1, 2\}$. Repetition does not matter, so $\{1, 1, 2\} = \{1, 2\}$. If you need order, you need a sequence or tuple; if you need repetition, a multiset. In code, this is exactly the difference between a `Set` and an array.

Sets are described in two ways:

- **Roster notation** lists the elements: $A = \{2, 3, 5, 7\}$.
- **Set-builder notation** gives a rule: $E = \{\, n \in \mathbb{Z} : n = 2k \text{ for some } k \in \mathbb{Z} \,\}$, "the set of integers $n$ such that $n$ is twice an integer". This is a filter, `integers.filter(isEven)`, written mathematically.

Standard sets: $\mathbb{N} = \{0, 1, 2, \dots\}$ (we include 0, as most computer-science texts do; check each book's convention), $\mathbb{Z}$ the integers, $\mathbb{Q}$ the rationals, $\mathbb{R}$ the reals, and $\varnothing$, the **empty set**, which has no elements.

The **cardinality** $|A|$ of a finite set is its number of elements. $|\{a, b, c\}| = 3$, $|\varnothing| = 0$, and $|\{\varnothing\}| = 1$: a box containing an empty box is not empty.

### Subsets and equality

<div class="box def">

<span class="tag">Definitions</span>

$A \subseteq B$ ($A$ is a **subset** of $B$) means every element of $A$ is in $B$: $\forall x\, (x \in A \to x \in B)$.
$A = B$ means $A \subseteq B$ and $B \subseteq A$.

</div>

Two consequences people find surprising: $\varnothing \subseteq A$ for **every** set $A$ (the implication "$x \in \varnothing \to x \in A$" is vacuously true), and $A \subseteq A$.

The definition of equality gives the standard way to **prove** two sets equal: show each is a subset of the other. This is called *double inclusion*, and you will use it constantly.

### Power sets

The **power set** $\mathcal{P}(A)$ is the set of all subsets of $A$. For $A = \{a, b, c\}$:
$$\mathcal{P}(A) = \{\varnothing, \{a\}, \{b\}, \{c\}, \{a,b\}, \{a,c\}, \{b,c\}, \{a,b,c\}\}.$$

<div class="box thm">

<span class="tag">Theorem</span>

If $|A| = n$, then $|\mathcal{P}(A)| = 2^n$.

</div>

*Proof idea.* To build a subset, go through the $n$ elements and decide for each one, independently, "in" or "out". That is $2 \times 2 \times \dots \times 2 = 2^n$ choices, each giving a different subset. (Lesson 1.2.4 makes "independent choices multiply" a precise rule, and 1.2.3 gives an induction proof.)

In code, a subset of an $n$-element set is an $n$-bit mask, which is why there are $2^n$ of them and why "try every subset" algorithms are exponential.

## Operations on sets

Let $U$ be a universal set containing everything under discussion.

| Operation | Notation | Definition | In code |
|:-|:-:|:-|:-|
| Union | $A \cup B$ | $\{x : x \in A \lor x \in B\}$ | `a.union(b)`, SQL `UNION` |
| Intersection | $A \cap B$ | $\{x : x \in A \land x \in B\}$ | SQL `INTERSECT`, inner join keys |
| Difference | $A - B$ | $\{x : x \in A \land x \notin B\}$ | SQL `EXCEPT` |
| Complement | $\overline{A}$ | $\{x \in U : x \notin A\}$ | `!predicate` |
| Cartesian product | $A \times B$ | $\{(a, b) : a \in A, b \in B\}$ | SQL `CROSS JOIN` |

Notice that every set operation is a logical connective in disguise: $\cup$ is $\lor$, $\cap$ is $\land$, complement is $\lnot$. So every logical equivalence from lesson 1.2.1 gives a set identity. De Morgan becomes
$$\overline{A \cup B} = \overline{A} \cap \overline{B}, \qquad \overline{A \cap B} = \overline{A} \cup \overline{B}.$$

The Cartesian product has $|A \times B| = |A| \cdot |B|$, and its elements are **ordered** pairs: $(1, 2) \ne (2, 1)$. A database table with columns of types $A$, $B$, $C$ is a subset of $A \times B \times C$.

### Proving a set identity

<div class="box thm">

<span class="tag">Proposition</span>

For all sets $A, B, C$: $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$.

</div>

*Proof.* We show double inclusion.

($\subseteq$) Let $x \in A \cap (B \cup C)$. Then $x \in A$, and $x \in B$ or $x \in C$. If $x \in B$, then $x \in A \cap B$. If $x \in C$, then $x \in A \cap C$. Either way $x \in (A \cap B) \cup (A \cap C)$.

($\supseteq$) Let $x \in (A \cap B) \cup (A \cap C)$. If $x \in A \cap B$, then $x \in A$ and $x \in B \subseteq B \cup C$. If $x \in A \cap C$, then $x \in A$ and $x \in C \subseteq B \cup C$. Either way $x \in A$ and $x \in B \cup C$, so $x \in A \cap (B \cup C)$.

Both inclusions hold, so the sets are equal. $\blacksquare$

This "let $x$ be an element of the left side, show it is in the right side" pattern is called **element chasing**. Venn diagrams are excellent for *guessing* identities and for finding counterexamples, but they are not proofs.

<div class="box warn">

<span class="tag">Common mistake</span>

Confusing $\in$ and $\subseteq$. For $A = \{1, 2\}$: $1 \in A$ is true, $\{1\} \subseteq A$ is true, but $\{1\} \in A$ is false and $1 \subseteq A$ is meaningless. In $\mathcal{P}(A)$, however, $\{1\} \in \mathcal{P}(A)$ is true.

</div>

## Functions

<div class="box def">

<span class="tag">Definition</span>

A **function** $f : A \to B$ assigns to **each** element $a$ of the **domain** $A$ **exactly one** element $f(a)$ of the **codomain** $B$. The **range** (or image) of $f$ is $\{f(a) : a \in A\} \subseteq B$.

</div>

Formally, a function is a subset $f \subseteq A \times B$ such that every $a \in A$ appears in exactly one pair $(a, b)$. Two requirements, and both matter: *every* input has an output (no undefined inputs), and the output is *unique*.

A JavaScript function that can throw, or that returns different results for the same input because it reads a clock, is not a mathematical function on the inputs you see. Making those hidden inputs explicit, or making failure part of the return type, is exactly what lesson 1.5 asks you to do.

### Injective, surjective, bijective

<div class="box def">

<span class="tag">Definitions</span>

Let $f : A \to B$.

- $f$ is **injective** (one-to-one) if different inputs give different outputs: $\forall a_1, a_2 \in A,\ f(a_1) = f(a_2) \to a_1 = a_2$.
- $f$ is **surjective** (onto) if every element of $B$ is hit: $\forall b \in B\ \exists a \in A,\ f(a) = b$.
- $f$ is **bijective** if it is both.

</div>

Examples, each with domain and codomain stated, because they change the answer:

| Function | Injective? | Surjective? |
|:-|:-:|:-:|
| $f: \mathbb{Z} \to \mathbb{Z},\ f(n) = 2n$ | yes | no (3 is not hit) |
| $g: \mathbb{Z} \to \mathbb{Z},\ g(n) = n^2$ | no ($g(-1) = g(1)$) | no |
| $h: \mathbb{R} \to \mathbb{R},\ h(x) = 3x + 1$ | yes | yes |
| $k: \mathbb{R} \to [0, \infty),\ k(x) = x^2$ | no | yes |
| `hash : strings → 64-bit ints` | no (finitely many outputs) | (depends on the hash) |

<div class="box ex">

<span class="tag">Worked example</span>

**Prove that $h : \mathbb{R} \to \mathbb{R}$, $h(x) = 3x + 1$ is bijective.**

*Injective.* Suppose $h(x_1) = h(x_2)$. Then $3x_1 + 1 = 3x_2 + 1$, so $3x_1 = 3x_2$, so $x_1 = x_2$.

*Surjective.* Let $y \in \mathbb{R}$. We need $x$ with $3x + 1 = y$. Solve on scratch paper: $x = (y-1)/3$. Now verify: $(y-1)/3$ is a real number, and $h\bigl((y-1)/3\bigr) = 3 \cdot \frac{y-1}{3} + 1 = y$. $\blacksquare$

Notice the shape of the surjectivity proof: it starts with an arbitrary $y$ in the codomain and *constructs* the $x$.

</div>

### Composition and inverses

If $f : A \to B$ and $g : B \to C$, the **composition** $g \circ f : A \to C$ is $(g \circ f)(a) = g(f(a))$. Read it right to left: first $f$, then $g$. Composition is how pipelines work: `xs.map(f).map(g)` is `xs.map(g ∘ f)`.

A function $f : A \to B$ has an **inverse** $f^{-1} : B \to A$, with $f^{-1}(f(a)) = a$ and $f(f^{-1}(b)) = b$, **if and only if $f$ is bijective**. This is why encryption must be a bijection on its inputs (you must be able to decrypt), while a hash need not be (you are not supposed to invert it).

### Cardinality and the pigeonhole principle

For finite sets $A$ and $B$:

- if $f : A \to B$ is injective, then $|A| \le |B|$;
- if $f : A \to B$ is surjective, then $|A| \ge |B|$;
- so a bijection exists exactly when $|A| = |B|$.

The contrapositive of the first line is the **pigeonhole principle**: if $|A| > |B|$, then **no** function $A \to B$ is injective, so two inputs must share an output. Put 13 people in a room and two share a birth month. Hash $2^{64} + 1$ different strings to 64-bit values and at least two collide, whatever the hash function.

For infinite sets, mathematicians **define** "$A$ and $B$ have the same size" to mean there is a bijection between them. This leads to surprises: $f(n) = 2n$ is a bijection from $\mathbb{N}$ to the even naturals, so there are "as many" even numbers as natural numbers. A set in bijection with $\mathbb{N}$ is **countable**; you can list its elements as a sequence. $\mathbb{Z}$ is countable ($0, 1, -1, 2, -2, \dots$), and so is $\mathbb{Q}$. But $\mathbb{R}$ is not: Cantor's diagonal argument (Book of Proof chapter 14) shows that any list of real numbers misses one. A consequence for computer science is that there are more problems than programs, so some problems have no algorithm at all.

## Relations

<div class="box def">

<span class="tag">Definition</span>

A **relation** $R$ on a set $A$ is a subset $R \subseteq A \times A$. We write $a \mathrel{R} b$ when $(a, b) \in R$.

</div>

Examples on $\mathbb{Z}$: $<$, $\le$, $=$, "divides", "has the same remainder mod 3 as". In software: "follows" on users, "depends on" on packages, "is a subtype of" on types. A relation between *two* sets, $R \subseteq A \times B$, is exactly a database table with two columns.

### Four properties

<div class="box def">

<span class="tag">Definitions</span>

A relation $R$ on $A$ is

- **reflexive** if $\forall a \in A,\ a \mathrel{R} a$;
- **symmetric** if $\forall a, b,\ a \mathrel{R} b \to b \mathrel{R} a$;
- **antisymmetric** if $\forall a, b,\ (a \mathrel{R} b \land b \mathrel{R} a) \to a = b$;
- **transitive** if $\forall a, b, c,\ (a \mathrel{R} b \land b \mathrel{R} c) \to a \mathrel{R} c$.

</div>

| Relation on $\mathbb{Z}$ | Reflexive | Symmetric | Antisymmetric | Transitive |
|:-|:-:|:-:|:-:|:-:|
| $=$ | ✓ | ✓ | ✓ | ✓ |
| $\le$ | ✓ | ✗ | ✓ | ✓ |
| $<$ | ✗ | ✗ | ✓ (vacuously) | ✓ |
| $a \mid b$ on positive integers | ✓ | ✗ | ✓ | ✓ |
| "differ by at most 1" | ✓ | ✓ | ✗ | ✗ |

"Not symmetric" and "antisymmetric" are different things: a relation can be both symmetric and antisymmetric ($=$), or neither. Explore with the inspector below, then try to build a relation that is symmetric and transitive but not reflexive.

### Equivalence relations and partitions

<div class="box def">

<span class="tag">Definition</span>

An **equivalence relation** is reflexive, symmetric and transitive. The **equivalence class** of $a$ is $[a] = \{x \in A : x \mathrel{R} a\}$.

</div>

The key example is **congruence modulo $n$**: $a \equiv b \pmod n$ means $n \mid (a - b)$. Modulo 3, the integers fall into three classes:
$$[0] = \{\dots, -3, 0, 3, 6, \dots\},\quad [1] = \{\dots, -2, 1, 4, \dots\},\quad [2] = \{\dots, -1, 2, 5, \dots\}.$$

<div class="box thm">

<span class="tag">Theorem</span>

The equivalence classes of an equivalence relation on $A$ form a **partition** of $A$: they are non-empty, every element is in one of them, and any two classes are either equal or disjoint.

</div>

*Proof of the main part.* Suppose $[a] \cap [b] \ne \varnothing$; we show $[a] = [b]$. Take $c$ in both, so $c \mathrel{R} a$ and $c \mathrel{R} b$. By symmetry $a \mathrel{R} c$, and by transitivity $a \mathrel{R} b$. Now let $x \in [a]$, so $x \mathrel{R} a$; with $a \mathrel{R} b$, transitivity gives $x \mathrel{R} b$, so $x \in [b]$. Hence $[a] \subseteq [b]$, and by the symmetric argument $[b] \subseteq [a]$. Every $a$ lies in its own class $[a]$ by reflexivity. $\blacksquare$

Equivalence relations are everywhere in engineering: "has the same hash bucket", "is the same user after normalising the email", "is in the same connected component". Whenever you group things, you are choosing an equivalence relation, and it had better be transitive. A "similarity" check that is not transitive (A looks like B, B looks like C, but A does not look like C) cannot be used to group items consistently.

### Partial orders

<div class="box def">

<span class="tag">Definition</span>

A **partial order** is reflexive, antisymmetric and transitive. It is a **total order** if, in addition, every two elements are comparable: $a \mathrel{R} b$ or $b \mathrel{R} a$.

</div>

$\le$ on numbers is total. $\subseteq$ on sets and "divides" on positive integers are partial: $\{1\}$ and $\{2\}$ are incomparable, and so are 2 and 3. Task dependencies form a partial order (strictly, a *strict* partial order, the irreflexive version): some tasks must come before others, and many pairs are unordered. Lesson 1.4.6 will show how to extend any finite partial order to a total order, which is topological sorting, the algorithm behind every build tool and package manager.

<div class="exercise">

<span class="tag">Exercise 2</span><span class="lvl-tag">★ basic</span>

True or false? (a) $\varnothing \in \{\varnothing\}$ (b) $\varnothing \subseteq \{\varnothing\}$ (c) $\{1\} \in \{1, \{1\}\}$ (d) $\{\{1\}\} \subseteq \{1, \{1\}\}$ (e) $|\{1, \{1, 2\}, 2\}| = 4$

<details><summary>Solution</summary>

(a) True: the only element is $\varnothing$. (b) True: $\varnothing$ is a subset of every set. (c) True: $\{1\}$ is listed as an element. (d) True: its only element, $\{1\}$, is an element of the right side. (e) False: the elements are $1$, $\{1, 2\}$ and $2$, so the cardinality is 3.

</details>

<div class="exercise">

<span class="tag">Exercise 3</span><span class="lvl-tag">★★ core</span>

Prove that $A - (B \cup C) = (A - B) \cap (A - C)$ by double inclusion.

<details><summary>Solution</summary>

($\subseteq$) Let $x \in A - (B \cup C)$. Then $x \in A$ and $x \notin B \cup C$, so $x \notin B$ and $x \notin C$. Hence $x \in A - B$ and $x \in A - C$, so $x \in (A - B) \cap (A - C)$.

($\supseteq$) Let $x \in (A - B) \cap (A - C)$. Then $x \in A$, $x \notin B$ and $x \notin C$. So $x \notin B \cup C$ (an element of the union would be in $B$ or in $C$), giving $x \in A - (B \cup C)$. $\blacksquare$

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 4</span><span class="lvl-tag">★★ core</span>

Disprove: for all sets $A, B, C$, if $A \cup C = B \cup C$ then $A = B$.

<details><summary>Solution</summary>

Counterexample: $A = \{1\}$, $B = \varnothing$, $C = \{1\}$. Then $A \cup C = \{1\} = B \cup C$, but $A \ne B$. (Union does not "cancel" the way addition does.)

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 5</span><span class="lvl-tag">★★ core</span>

For each function, decide injective and surjective, and prove your answers.
(a) $f : \mathbb{Z} \to \mathbb{Z}$, $f(n) = n + 5$.
(b) $g : \mathbb{Z} \times \mathbb{Z} \to \mathbb{Z}$, $g(m, n) = m + n$.
(c) $h : \mathbb{N} \to \mathbb{N}$, $h(n) = \lfloor n/2 \rfloor$.

<details><summary>Solution</summary>

(a) **Bijective.** Injective: $n_1 + 5 = n_2 + 5 \Rightarrow n_1 = n_2$. Surjective: for any $m \in \mathbb{Z}$, $f(m - 5) = m$.

(b) **Surjective, not injective.** Surjective: for any $k$, $g(k, 0) = k$. Not injective: $g(1, 0) = g(0, 1) = 1$ but $(1, 0) \ne (0, 1)$.

(c) **Surjective, not injective.** Surjective: for any $m \in \mathbb{N}$, $h(2m) = m$. Not injective: $h(0) = h(1) = 0$.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 6</span><span class="lvl-tag">★★ core</span>

Prove that if $f : A \to B$ and $g : B \to C$ are both injective, then $g \circ f$ is injective.

<details><summary>Solution</summary>

Suppose $(g \circ f)(a_1) = (g \circ f)(a_2)$, that is, $g(f(a_1)) = g(f(a_2))$. Since $g$ is injective, $f(a_1) = f(a_2)$. Since $f$ is injective, $a_1 = a_2$. So $g \circ f$ is injective. $\blacksquare$

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 7</span><span class="lvl-tag">★★ core</span>

On $\mathbb{Z}$, define $a \mathrel{R} b$ when $a - b$ is even. Prove that $R$ is an equivalence relation and describe its classes.

<details><summary>Solution</summary>

*Reflexive:* $a - a = 0 = 2 \cdot 0$ is even. *Symmetric:* if $a - b = 2k$, then $b - a = 2(-k)$ is even. *Transitive:* if $a - b = 2k$ and $b - c = 2\ell$, then $a - c = (a - b) + (b - c) = 2(k + \ell)$ is even. The classes are $[0]$, the even integers, and $[1]$, the odd integers. This is congruence mod 2. $\blacksquare$

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 8</span><span class="lvl-tag">★★ core</span>

Show that "divides" is a partial order on the positive integers, but not on all of $\mathbb{Z}$. Which property fails on $\mathbb{Z}$?

<details><summary>Solution</summary>

On positive integers: *reflexive*, $a = a \cdot 1$. *Transitive*, proved in lesson 1.2.1, exercise 6. *Antisymmetric*: if $a \mid b$ and $b \mid a$ with $a, b > 0$, then $b = ax$ and $a = by$ for positive integers $x, y$, so $a = axy$, so $xy = 1$, so $x = y = 1$ and $a = b$.

On $\mathbb{Z}$ (excluding 0 as a divisor), antisymmetry fails: $2 \mid -2$ and $-2 \mid 2$, but $2 \ne -2$.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 9</span><span class="lvl-tag">★★★ stretch</span>

Find the flaw: "Claim: a symmetric and transitive relation is reflexive. Proof: Let $a \in A$. Take $b$ with $a \mathrel{R} b$. By symmetry $b \mathrel{R} a$. By transitivity $a \mathrel{R} a$." Give a counterexample, and check it in the relation inspector.

<details><summary>Solution</summary>

The flaw is "take $b$ with $a \mathrel{R} b$": nothing guarantees that such a $b$ exists. Counterexample on $A = \{1, 2, 3\}$: $R = \{(1,1), (1,2), (2,1), (2,2)\}$. It is symmetric and transitive, but $(3, 3) \notin R$ because 3 is related to nothing. Even simpler: the empty relation on a non-empty set.

</details>
</div>

<div class="exercise">

<span class="tag">Exercise 10</span><span class="lvl-tag">★★★ stretch</span>

A URL shortener maps long URLs to 7-character codes from the alphabet $[a\text{–}z, A\text{–}Z, 0\text{–}9]$. (a) How many codes exist? (b) Must the mapping from URLs to codes be injective for the service to work? (c) Once more URLs have been shortened than there are codes, what does the pigeonhole principle say?

<details><summary>Solution</summary>

(a) $62^7 = 3{,}521{,}614{,}606{,}208$, about $3.5 \times 10^{12}$.

(b) Yes, on the set of URLs actually stored: two URLs sharing a code would make redirection ambiguous. The decoding direction must be a function from codes to URLs, which requires the encoding to be injective on stored URLs.

(c) If more than $62^7$ distinct URLs are stored, no injective mapping into 7-character codes exists, so two URLs must share a code. The service must then use longer codes. (Collisions will appear far earlier if codes are random rather than sequential; lesson 1.2.4 on the birthday paradox shows how much earlier.)

</details>

## Summary

- Sets ignore order and repetition. Prove $A = B$ by showing $A \subseteq B$ and $B \subseteq A$.
- Set operations mirror logical connectives, so logical equivalences become set identities.
- A function gives each input exactly one output. Injective: no collisions. Surjective: every target hit. Bijective: invertible.
- Pigeonhole: if $|A| > |B|$, some two elements of $A$ share an image under any $f : A \to B$.
- Equivalence relations (reflexive, symmetric, transitive) are exactly the ways of grouping a set into disjoint classes. Partial orders (reflexive, antisymmetric, transitive) model "comes before".
